# sentinel-core: Sentinel's own directory/file brute-force wordlist.
#
# Format: one entry per line, `category<TAB>path`. Lines starting with '#' and blank lines are ignored.
# Categories: config | backup | vcs | admin | api.
# Paths are relative to the site root: no leading '/', ASCII only, no whitespace, '#', '?', '%',
# '..' or the string FUZZ, at most 200 characters, each path listed once.
# Every path is requested with a plain GET, so the list holds nothing that could change state on
# a client site (no logout, delete, reset, install/setup, upload handlers, checkout, cron, ...).
# Archives and dumps (.zip .tar .tar.gz .tgz .gz .bz2 .7z .rar .sql .sql.gz .dump .db .sqlite) are
# always category 'backup': they are checked with a HEAD request only and never downloaded.
# Every path probed by sentinel_checks.passive.exposed_files.PROBES is included.
# Rules are enforced by packages/recon/tests/test_wordlists.py. Entries are grouped into themed sections.
